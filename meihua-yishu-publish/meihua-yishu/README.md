# 梅花易数 · 邵雍一脉（meihua-yishu）

WorkBuddy 技能：梅花易数起卦断卦方法论的总入口。

## 它能做什么

- **先天起卦**：年月日时 / 数字 / 物数 / 声音 / 字画 → 卦（卦以八除、爻以六除）
- **后天端法**：见物 / 人 / 声 / 色 + 方位起卦、为人占、字占
- **体用分判**：无动爻为体（主/我），有动爻为用（事）；互卦为中应、变卦为末应
- **五行生克比和断吉凶**：用生体 / 比和 / 体克用吉，用克体凶，体生用为泄气
- **应期推算**：体旺衰、坐行卧立定迟速，生体之日为吉期、克体之日为凶期
- **外应（三要十应）**：占时耳闻目见皆为兆，内卦与外应矛盾以理校之
- **八卦万物类象 / 十八占 / 射覆观物 / 坐端加数**

# 梅花易数 — 全书概览

**作者**：托名宋·邵雍（邵康节）；序为清·黄宗羲撰；实际成书约明清之际，借邵雍之名传世。
**性质**：占卜（术数）实操手册，一套"以数起卦、以卦起数"的简便占法。
**公版来源**：维基文库《梅花易数》原文（序 + 卷一·象数易理篇 + 卷二·体用生克篇 + 卷三·断占总诀篇 + 附录）。

## 一句话主旨
以最简省的物/数/时，起出本卦、互卦、变卦，分体用、察五行生克与旺衰、参三要十应外应，断吉凶与应验之期。

## 骨架（七论）
1. **象数基础**：八卦数、五行生克、卦气旺衰、天干地支、八卦象例（卷一·之一）。
2. **起卦之法**：先天数起卦（年月日时/物数/声音/字占）与后天端法（卷一·之一/之二/之三）。
3. **体用生克**：成卦分体用，体为主、用为事、互为中应、变为末应；五行生克比和定吉凶（卷二·之一）。
4. **分类占断**：体用生克套进十八类事项（卷二·之二）。
5. **外应三要十应**：耳目心所感外兆须与内卦合参（卷二·之三/之四）。
6. **断诀与应期**：互变/生克衰旺动静/坐端/克应之诀（卷三·之一）。
7. **观物射覆**：变爻为主、克应为辅，推断笼中手中之物（卷三·之三）。

## 关键术语速查
- 先天之数：未得卦先得数，以数起卦（数→卦）。
- 后天之数：先得卦后起数，以卦起数（卦→数），即"端法"。
- 体/用：无动爻者为体（主），有动爻者为用（事）。
- 互卦/变卦：互去初上取中四爻为中应，变动爻阴阳互变为末应。
- 比和：体用五行同类，吉。
- 三要/十应：耳闻目见心念 + 天/地/人/时令/方/动/静/言/声/色等外应。
- 克应：应验之期。

## 作者的局限（读时打折扣）
- "数定万物、卦可前知"前提无法证伪；占验故事多为事后追述、选择性记载。
- 卦气旺衰是古人对自然节律的拟象，非可重复验证规律。
- 解卦中"变通/以理校数"给了巨大主观裁量，故"准"与"不准"皆可被解释。

# 五行生克断诀（体用生克比和）

## R — 原文 (Reading)

> 體克用，諸事吉；用克體，諸事凶。體生用，有耗失之患；用生體，有進益之喜。體用比和，則百事順遂。
> — 卷二·体用生克篇之一·体用总诀

> 體宜受用卦之生，用宜見卦體之克。體盛則吉，體衰則凶。用克體固不宜，體生用亦非利。體党多而體勢盛，用党多則體勢衰。
> — 卷二·体用总诀

---

## I — 方法论骨架 (Interpretation)

分完体用互变后，用**五行生克**判吉凶。把体卦、用卦、互卦、变卦都换成五行（乾兑金、坤艮土、震巽木、坎水、离火），然后看它们对"体"的关系：

| 关系 | 含义 | 吉凶 |
|---|---|---|
| 用生体 / 互变生体 | 事来益我 | 吉（进益之喜） |
| 体克用 | 我制其事 | 吉 |
| 体用比和（同行） | 同心协力 | 吉（百事顺遂） |
| 用克体 | 事来伤我 | 凶 |
| 体生用 | 我泄气以成事 | 非利（耗失之患） |

进阶三招：
1. **看体党/用党**：互变皆同体之行者，体党多→体盛；互变皆同用之行，用党多→体衰。
2. **看卦气旺衰**：体卦乘旺（春木夏火秋金冬水四季土）虽被克亦无大害；克体之卦乘旺则真凶。
3. **真生真克分轻重**：乾兑金体遇炉中真火则克，遇红紫之色、灯烛微火则只是"不顺畅"；震巽木体遇快刀巨斧则克，遇钗钏之金不克（卷三·体用生克之诀）。

生体之卦不同，喜事性质不同：乾生体主公门/功名/金宝，坤生体主田土/阴人/布帛，震生体主山林/东方财，坎生体主北方/水边财……（卷二·八卦生体详列，见下卡引申）。

## A1 — 书中的应用 (Past Application)

### 案例 1：牡丹占（用克体）
- **问题**：巳年三月十六日卯时观牡丹，何以知"明日午时为马践毁"？
- **用法**：得天风姤，巽木体被乾金克，互重乾（克体多），无生体之卦→无生意；乾为马、午时离明→马践。
- **结论**：必毁。
- **结果**：次日午时贵官二马相啮，花尽践毁。

### 案例 2：少年有喜色占（用不生体而互变俱生）
- **问题**：山火贲，艮为体，离为用（用不生体本不吉），何以断喜？
- **用法**：卦辞"束帛戋戋"吉，且互变俱生体（离体得生）→二者俱吉、互变俱生愈见其吉。
- **结论**：十七日内有聘币喜。
- **结果**：至期定亲。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 已分体用互变，要**判断这件事吉还是凶**时。
2. 看到"体克用""用生体""比和"等术语想理解其吉凶含义时。
3. 卦中既有生体又有克体，不知如何综合时。

### 语言信号
- "体用生克怎么断""用克体凶吗""比和是吉吗""体生用为什么不好""体党用党""卦气旺衰怎么算"
- "how to judge auspice from ti-yong five-phase"

- 与 `shiba-zhan`：本张是通用断诀，那张是把本诀套进十八类具体事项。

## E — 可执行步骤 (Execution)

1. **标五行**：体/用/互/变各属何行（乾兑金、坤艮土、震巽木、坎水、离火）。
   - 完成标准：四卦五行标注完。
2. **列关系**：逐一判 用/互/变 对"体"是 生/克/比和/被体生。
   - 完成标准：关系清单。
3. **定基调**：有生体/比和/体克用→倾向吉；有克体→倾向凶；体生用→耗。
   - 完成标准：初步吉凶。
4. **查旺衰**（交 `guaqi-yingqi`）：体乘旺否？克体之卦乘旺否？体旺逢克可缓，体衰逢克大凶。
   - 完成标准：旺衰修正。
5. **定喜事性质**：若有生体之卦，依"何卦生体"断喜属（乾=公门金宝、坤=田土阴人……）。
   - 完成标准：吉凶定性 + 性质描述。
6. **必要时查类象**（交 `bagua-leixiang` / `shiba-zhan`）：取具体事项细节。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 还没分体用 → 先 `ti-yong-fen`。
- 单看卦名（如"革=变革"）就断吉凶 → 梅花以体用生克为据，不以卦名直断（卷二·卦断遗论）。

### 作者在书中警告的失败模式
- **只数生克不论旺衰**："體卦氣衰，而克體之卦氣旺，是其凶甚矣"（卷三·衰旺之诀）——体衰逢旺克，问病必死问讼必败。
- **真火假火不分**：乾兑金体遇炉火真火则凶，遇红紫之色、一灯之烛只是小不利（卷三·体用生克之诀）。
- **拘执比和**：体用互变俱比和本应吉，但"寺为纯阳人居得纯阴卦=群阴剥阳"可破例（卷二·卦断遗论，亦见 `lilun-biantong`）。

### 作者的盲点 / 时代局限
- 五行生克→人事吉凶的映射是类比式，非因果；同一卦不同解卦者结论可异。

### 容易混淆的邻近方法论
- 纳甲六爻的"六亲生克"与梅花"体用生克"框架相似但取用不同，勿混。

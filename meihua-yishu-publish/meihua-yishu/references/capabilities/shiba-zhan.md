# 十八占分类断法

## R — 原文 (Reading)

> 凡占家宅，以體為主，用為家宅。體克用，則家宅多吉，用克體，則家宅多凶。體生用，多耗散……用生體，多進益……體用比和，家宅安穩。
> — 卷二·体用生克篇之二·家宅占第三

> 凡占失物，以體為主，用為失物。……又以變卦為失物之所在。如變是乾，則覓於西北或公榭樓閣……圓器之中，或高亢之地。
> — 卷二·失物占第十五

## I — 方法论骨架 (Interpretation)

十八占是"体用生克"这把万能钥匙，落到**十八类具体事项**上的使用说明书。每一占都先规定"体代表什么、用代表什么"，再用同一套生克比和规则判定，并附加该类特有的细节：

| 占类 | 体= | 用= | 该类要点 |
|---|---|---|---|
| 天时 | 不分体用，全观诸卦 | — | 离多晴、坎多雨、坤阴晦、乾晴明、震雷巽风、艮久雨必晴 |
| 人事 | 己身 | 所问之事 | 生体进益、克体耗失、比和吉利 |
| 家宅 | 己 | 家宅 | 体克用吉、用克体凶、用生体进益 |
| 屋舍 | 己 | 屋舍 | 体克用居吉、用生体门户兴 |
| 婚姻 | 所占之家 | 所婚之家 | 用生体易成、用克体不可成 |
| 生产 | 母 | 生 | 宜旺宜相生；阳卦阳爻多男、阴卦阴爻多女 |
| 饮食 | 己 | 饮食 | 有坎则有酒、有兑则有食 |
| 求谋 | 己 | 所谋 | 体克用成但迟、用克体不成 |
| 求名 | 己 | 名 | 体克用名成迟、用生体易成 |
| 求财 | 己 | 财 | 体克用有财、用克体无财 |
| 交易 | 己 | 财 | 体克用有财、用生体即成 |
| 出行 | 己 | 所行 | 体克用可行、用克体有祸 |
| 行人 | 己 | 行人 | 用生体即归、用克体不归 |
| 谒见 | 己 | 所见人 | 体克用可见、用生体见且有得 |
| 失物 | 己 | 失物 | 变卦定方位（乾西北公榭…兑西方废井…） |
| 疾病 | 病人 | 病症 | 体旺逢生愈、体衰逢克死；克体卦定医药（离热坎冷艮温补乾兑凉） |
| 官讼 | 己 | 对辞/官 | 体克用己胜、用克体人胜 |
| 坟墓 | 己 | 坟墓 | 用生体葬之兴隆、用克体葬之凶 |

通用口诀（诸事响应歌）："大抵体宜用卦生，旺相谋为终有益。比和为吉克为凶，生用亦为凶兆矣。"

## A1 — 书中的应用 (Past Application)

### 案例 1：失物占（变卦定方位）
- **问题**：物失何处？
- **用法**：体为主、用为失物；变卦为所在。变乾→西北公榭楼阁金石之傍圆器高亢地；变坤→西南田野仓禀瓦方器；变震→东方山林闹市；变坎→北方水边溪井；变离→南方庖厨炉冶明窗文书侧；变艮→东北山林石傍土穴；变兑→西方泽畔败垣废井。
- **结论**：依变卦方位寻。

### 案例 2：疾病占（克体定医药与死期）
- **问题**：病何如？
- **用法**：体宜旺不宜衰；乾上坤下初爻动=生体（变震木、互巽艮俱生）→不灾逢生即愈；第二爻动=变坎泄体、互巽离风火扇炉俱克→焚尸之象死无疑。
- **结论**：依动爻定生死，依克体卦定医药（离热、坎冷、艮温补、乾兑凉）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 起卦后想问"**具体某类事**（婚姻/求财/失物/疾病…）该怎么套体用"时。
2. 想知道"失物在哪、病吃什么药、行人几时回"等特定问题怎么从卦取象时。

### 语言信号
- "占婚姻/求财/失物/疾病/出行/行人/官讼怎么断""梅花易数 十八占""失物变卦方位""疾病医药取象"
- "how to interpret for marriage / missing object / illness"

### 与相邻 skill 的区分
- 与 `wuxing-shengke`：本卡是"分类套用表"，那张是"通用生克规则"。本卡每类调用那张的规则并加该类细节。
- 与 `bagua-leixiang`：本卡用类象定"体/用/变卦的具体所指"，类象表是查字典。

## E — 可执行步骤 (Execution)

1. **定位占类**：用户问的是十八占中哪一类？
   - 完成标准：占类确定。
2. **定体用所指**：按上表把"体=什么、用=什么"代入。
   - 完成标准：体用语义化。
3. **套生克规则**：交 `wuxing-shengke` 判吉凶（生体/比和吉、克体凶、体生用耗）。
   - 完成标准：吉凶基调。
4. **取该类细节**：如失物查变卦方位、疾病查克体卦定医药、生产查阴阳爻定男女。
   - 完成标准：具体结论。
5. **必要时取象**：交 `bagua-leixiang` 把卦象译成具体物/人/方位。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 还不知道体用怎么分 → 先 `ti-yong-fen`。
- 问的是通用吉凶而非具体事项 → 用 `wuxing-shengke` 即可。

### 作者在书中警告的失败模式
- 占天时"不分体用，全观诸卦"：天数看诸卦五行多寡（离多晴坎多雨），不可机械套体用（卷二·天时占）。
- 疾病"体衰而逢克，断无存日"；若误判体旺则漏凶（卷二·疾病占）。

### 作者的盲点 / 时代局限
- 分类表以古代生活（官场、农耕、男女角色）为语境，现代事项须类比迁移。

### 容易混淆的邻近方法论
- 十八占的"婚姻/生产"等规则与 `bagua-leixiang` 的人物类象互补但不同层。

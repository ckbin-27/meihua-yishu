# 先天起卦法（数→卦）

## R — 原文 (Reading)

> 年月日為上卦。年月日加時總數為下卦。又以年月日時總數取爻。如子年一數……直至亥年十二數。月如正月一數……日數如初一一數……以上年月日共計幾數，以八除之，以餘數作卦。……以六除，餘數作動爻。
> — 卷一·象数易理篇之一·年月日時起例

> 乾，一；兌，二；離，三；震，四；巽，五；坎，六；艮，七；坤，八。
> — 卷一·周易卦數

---

## I — 方法论骨架 (Interpretation)

先天起卦法的本质是"先有数、后成卦"：把目之所见的数（年月日时、物之件数、声音句数、字数画数、丈尺尺寸）按先天八卦数（乾1兑2离3震4巽5坎6艮7坤8）映射成卦，再用"卦以八除、爻以六除"把任何大数折成 0–7 的卦序与 0–5 的动爻。

规则链：
- **上卦** =（起卦所用的数）除八取余（数恰为8则作坤，不必除）。
- **下卦** =（起卦之数 + 时数）除八取余。
- **动爻** =（总数）除六取余；余1则初爻动，余0（整除）则上六动。

同一套"除八取余→卦、除六取余→爻"可套不同数源：年月日时、可数之物、所闻之声、所书之字、丈尺尺寸，只是"取哪些数相加"不同。

## A1 — 书中的应用 (Past Application)

### 案例 1：观梅占（年月日时起例）
- **问题**：辰年十二月十七日申时，二雀争枝坠地，怪而欲占。
- **用法**：辰5+12+17=34，除八余2→兑（上）；加申9=43，除八余3→离（下）；总数43除六余1→初爻动。得泽火革，初爻变咸，互乾巽。
- **结论**：兑金为体被离火克，互巽木又逢乾金克（巽为股），变艮土生兑金→伤股而不死。
- **结果**：明晚女子折花坠伤股，果验。

### 案例 2：邻夜叩门借物占（闻声起例）
- **问题**：酉时扣门一声又五声，云借物，令子占。
- **用法**：一声乾(上)、五声巽(下)，加酉10=16，除六余4动→天风姤变巽，互重乾。三乾金二巽木，金短木长。
- **结论**：金短木长之器。
- **结果**：子断"锄"，先生据"夕晚安用锄"改断"斧"，果借斧。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 想用"当下的时间/所见之数/所闻之声/所书之字"起一卦时。
2. 拿到一组数（如生日、日期、物品件数）想映射成八卦时。
3. 读《梅花易数》占例，看不懂"为何这样起上卦下卦动爻"时。

### 语言信号
- "用时间/日期怎么起卦""年月日时起卦""物数/声音/字数怎么起卦""先天起卦""卦以八除、爻以六除怎么算"
- "how to cast a gua from a number / date / time"

### 与相邻 skill 的区分
- 与 `qigua-houtian`：本卡是**数→卦**（先有数）；那张是**卦→数**（先见物象/方位再配时数）。
- 与 `ti-yong-fen`：本卡只负责"起出本卦互卦变卦"，不负责"怎么读卦"，读完卦交给体用卡。

## E — 可执行步骤 (Execution)

1. **定数源**：明确用哪一种——年月日时 / 物数 / 声音句数 / 字数画数 / 丈尺尺寸。
   - 完成标准：数源选定且可数。
2. **算上卦**：把对应数除八取余，余数 1–8 对应乾→坤（余0或恰8 取坤）。
   - 完成标准：得到一个上卦。
3. **算下卦**：上卦之数 + 时数（或其他约定加数），再除八取余得下卦。
   - 完成标准：得到一个下卦，本卦 = 上+下。
4. **算动爻**：上+下+时 的总数除六取余（余1→初爻，余0→上六）。
   - 完成标准：得到动爻位置。
5. **出互变**：去初上取中四爻得互卦；动爻阴阳互变得变卦。
   - 完成标准：本/互/变三卦齐备，交 `ti-yong-fen` 判体用。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 已先见到具体物象/方位、想用"端法"起卦时 → 改 `qigua-houtian`。
- 起完卦需要判断吉凶时 → 本卡不负责断，交 `ti-yong-fen` / `wuxing-shengke`。

### 作者在书中警告的失败模式
- 数源错配：字占体系里"一字取画、二字平分、四字以上用平仄"（一字平声1上声2去声3入声4），不可一律数画数（卷一·一字占至十一字占）。错用则卦错。
- 动静取爻须"取爻当以时加之"：后天起卦定爻**必须加时数**，今人多不加时则"止一爻动，更无移易变通"（卷二·先天后天论）。

### 作者的盲点 / 时代局限
- 以"数定万物"为前提，数→卦的映射本身不可证伪。

### 容易混淆的邻近方法论
- 与皇极经世"一元十二会"等宏大历数不同，梅花只取"年月日时之序数"作简便起卦，勿混。

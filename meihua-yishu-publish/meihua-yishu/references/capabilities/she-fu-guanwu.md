# 射覆观物法（变爻为主）

## R — 原文 (Reading)

> 凡觀物，以變卦為主，應用之應驗也。如得乾，初爻變為巽，金刀削過之木物。二爻動，變為離，乃火中鍛鍊之金。
> — 卷三·断占总诀篇之三·观物看变爻为主

> 又訣，體用斷物之妙……其所以生體者，為可食之物；克體者，為可近人之穢物。體生者，為不成之器；體克者，為破碎損折之物；比和者，乃有用成器之物。
> — 卷三·占物类例

---

## I — 方法论骨架 (Interpretation)

射覆/观物是梅花在"猜物"这一特殊场景的演练：给你一个笼中/手中/覆物之器，推断里面是什么。它的核心口诀是"**以变卦为主**"——变爻所在决定物的本质，再辅以体用生克定物性：

- **生体**：可食之物（艮土生乾金→有土中物可食）。
- **克体**：可近人之秽物（坎水克离火→水边污物）。
- **体生**：不成之器（我泄气以成，故而"不成"）。
- **体克**：破碎损折之物。
- **比和**：有用成器之物。

进阶技巧：
- **物数为体诀**：不只用本卦为体，卦之多者（如乾金多）亦可为体，看刚柔生旺定物（卷三·物数为体诀）。
- **变在五六爻**：多能飞动之物。
- **观物克应法**：成卦未决时见圆物即断圆物、见负土者断土中物、见刚健断刚健（卷三·观物克应法）。
- **观物趣时诀**：春得震离为花、夏得震为有声物、秋得兑为毁折成器、冬得坤为无用土物（卷三·观物趣时诀）。
- **观物用易例**：引《易》爻辞断物（"拔茅茹以其汇"→连根草木；"鼎玉铉"→虽圆今缺之玉）。

## A1 — 书中的应用 (Past Application)

### 案例 1：笼盛物（引爻辞）
- **问题**：有人以笼盛物，算得地天泰之初变升，互震兑。
- **用法**：引爻辞"拔茅茹，以其汇"→连根草木；互震青、兑黄根→色青根黄。
- **结论**：干根之草木，新采于土中。
- **结果**：开视乃草木连根，新采于土中。

### 案例 2：钟覆物（变爻为主）
- **问题**：以钟覆物占，得火风鼎之雷风恒。
- **用法**：引"鼎玉铉大吉"，互乾兑→虽圆而今毁缺、色白可用。
- **结论**：有声价之气、虽圆今缺之白物。
- **结果**：开视乃玉条环，果破矣。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 玩/练"射覆"——猜手中、笼中、覆物之器里是什么时。
2. 想从一卦推断"某物的材质/形状/可否食/成器否"时。
3. 读到"变爻为主""物数为体"术语时。

### 语言信号
- "射覆怎么断""观物法""猜物""变爻为主""笼中物/手中物占""梅花易数 戏验"
- "she-fu / guess the object / object divination"

### 与相邻 skill 的区分
- 与 `wuxing-shengke`：本卡是"把生克套到'物性'上（可食/秽/成器/破碎）"，那张是通用吉凶。
- 与 `bagua-leixiang`：本卡用类象定"物是什么"，类象表是查字典。

## E — 可执行步骤 (Execution)

1. **起卦**：用 `qigua-xiantian`/`qigua-houtian` 为所覆之物起卦。
   - 完成标准：本互变三卦。
2. **定体用**：依 `ti-yong-fen` 分体用。
   - 完成标准：体用明确（必要时用"物数为体诀"）。
3. **看变爻为主**：动爻阴阳互变定物本质（初爻动变巽=木物、二爻动变离=火炼金……）。
   - 完成标准：物本质。
4. **定物性**：依生体/克体/体生/体克/比和断可食/秽/不成器/破碎/成器。
   - 完成标准：物性。
5. **趣时+克应+引辞**：交 `bagua-leixiang` 取具体象，必要时引《易》辞（如"拔茅茹"）定细节。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 问的是人事吉凶而非"物" → 用 `shiba-zhan` / `wuxing-shengke`。
- 还没起卦 → 先 `qigua-xiantian`/`qigua-houtian`。

### 作者在书中警告的失败模式
- "值六虚冲破，则必无物而空手矣"——逢六冲空破，可能根本无物（卷三·万物戏验）。
- 只数卦不顾时："春震巽、夏离、秋乾兑、冬坎皆当为可用成器之物，否则为无用"——趣时而定（卷三·观物趣时诀）。

### 作者的盲点 / 时代局限
- 射覆以"巧合验证"为主，可重复性差，宜作游戏/思维训练，不宜当真。

### 容易混淆的邻近方法论
- 射覆的"变爻为主"是观物特例；通用断卦仍以"体用互变"时序为主。

# 八卦万物类象（取象辞典）

## R — 原文 (Reading)

> 乾：天、父、老人、官貴、頭、骨、馬、金寶、珠玉、水果、圓物、冠、鏡、剛物、大赤色、水寒。
> 坤：地、母、老婦、土、牛、金、布帛、文章、輿輦、方物、腹、裳、黑色、黍稷、書、米、穀。
> 震：雷、長男、足、髮、龍、百蟲、蹄、竹、草木、青碧綠色、樹、木核、柴、蛇。
> — 卷一·象数易理篇之二·八卦万物属类

> 乾為天、為圓、為君、為父、為首、為金、為玉……為良馬、為老馬、為瘠馬、為駁馬、為木果。
> — 卷三·断占总诀篇之四·卦应

---

## I — 方法论骨架 (Interpretation)

八卦万物类象是梅花的"字典"：把抽象八卦翻译成具体的人、物、方位、身体、时令、颜色、声音，供**起卦时取象**（端法）与**断卦时取义**（把体用五行译成具体人事）两用。

核心八象（起卦/取义通用）：
- **乾☰**：天、父、老人、官贵、头、骨、马、金宝、珠玉、圆物、冠镜、刚物、大赤色；五行金；西北。
- **坤☷**：地、母、老妇、土、牛、布帛、文章、方物、腹、裳、黑黄、黍稷、书米谷；五行土；西南。
- **震☳**：雷、长男、足、发、龙、百虫、竹草木、青碧绿、树、柴、蛇；五行木；东。
- **巽☴**：风、长女、僧尼、鸡、股、草木、香、绳、眼、羽毛、帆扇、直长物；五行木；东南。
- **坎☵**：水、雨雪、中男、豕、耳、血、月、盗、沟渎、弓轮、水族鱼盐酒；五行水；北。
- **离☲**：火、雉、日、目、电、中女、甲胄戈兵、文书、干燥物、红赤紫、花、文人；五行火；南。
- **艮☶**：山、少男、童子、狗、手指、径路门阙、果蓏、鼠虎、黄；五行土；东北。
- **兑☱**：泽、少女、巫、舌、妾、肺、羊、毁折物、带口之器、废缺物、奴婢；五行金；西。

卷三另有"卦应"扩展（如乾为天圆君父、天文雪老阳、身体顶面颊、疾病太阳脉弦紧等），以及"万物赋/饮食篇"细碎类象，供查。

## A1 — 书中的应用 (Past Application)

### 案例 1：取象起卦（端法）
- **问题**：见老人→何卦？见少女→何卦？赤衣→何卦？
- **用法**：老人属乾、少女属兑、赤衣属离（卷一·为人占）。
- **结论**：以此定上卦/下卦。

### 案例 2：取象断义（饮食占）
- **问题**：饮食占互见兑，席上有何？
- **用法**：兑为口、为食、为羊、为辛辣→主羊肉或辛辣之食、宴集（卷二·饮食占）。
- **结论**：依类象得具体物。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 端法起卦时，要把"所见人/物/色"翻译成八卦时。
2. 断卦时，要把"体用五行"翻译成具体的人事/方位/物/病位时。
3. 查"乾代表什么、兑代表什么、某卦对应身体哪部位"时。

### 语言信号
- "乾/坤/震/巽/坎/离/艮/兑代表什么""八卦类象""万物类属""某卦对应什么人/物/身体/方位""梅花易数 类象表"
- "bagua symbolism / what does gua X represent"

### 与相邻 skill 的区分
- 与 `qigua-houtian`：本卡是"字典"，那张是"用字典起卦的程序"。
- 与 `shiba-zhan`：本卡提供"体/用/变卦的具体所指"，那张是分类断法框架。

## E — 可执行步骤 (Execution)

1. **明用途**：是要"起卦取象"还是"断卦取义"？
   - 完成标准：用途明确。
2. **查本卡八象**：按上表定位八卦对应的人/物/方/色/行。
   - 完成标准：取到基础类象。
3. **按需扩展**：饮食查"万物赋/饮食篇"、身体病位查"卦应"、细物查卷三扩展。
   - 完成标准：取到专用类象。
4. **回交主线**：把类象交 `qigua-houtian`（起卦）或 `shiba-zhan`/`wuxing-shengke`（断卦）使用。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 本卡只是字典，不涉及"怎么起卦/怎么断吉凶"——须交对应卡。
- 先天数起卦（无具体物象）时本卡用不上。

### 作者在书中警告的失败模式
- 类象过宽："右萬物之象，庶事之多不止於此。占者宜各以其類而推之耳"（卷一·八卦类象末）——须按所占之事"以类而推"，不可张冠李戴。
- 动静之辨：乾马坤牛属"动者"，井沼山石属"静者"；同是水，井沼静、人担水动（卷三·体用动静之诀）。

### 作者的盲点 / 时代局限
- 类象体系以古代名物为语境（舆辇、甲胄、布帛），现代须类比迁移。

### 容易混淆的邻近方法论
- 本卡类象与《说卦传》同源，但梅花取其"简便取象"用，不必穷究经学。

# 坐端诀与加数诀（进阶操作）

## R — 原文 (Reading)

> 坐端之訣，以我之所坐為中，八位列于八方，占卦決斷之。須虛心待應，坐而端之，察其八卦八方應兆，以為占卜事端之應。……如乾上有土生之，或乾宮有諸吉兆，則尊長老人分上，見吉慶大事。
> — 卷三·断占总诀篇之一·占卜坐端之诀

> 先生以各姓而加數，遂斷之而皆驗。蓋三家求占，有田姓者，王姓者，韓姓者。若寅年三數、十二與一，共十六，加王姓四畫，得二十數……
> — 卷二·体用生克篇之五·起卦加数例

---

## I — 方法论骨架 (Interpretation)

两张"进阶操作"卡，解决两个特殊但常见的实战问题：

**一、坐端诀（以坐定八方）**
占卜时以**占者自己落座之处为中宫**，把八卦排布于八方（乾西北、兑西、离南、震东、巽东南、坎北、艮东北、坤西南）。观察各方出现的应兆（物/人/色/声），配该方之卦，定"各家分上"的吉凶：乾方有土生或有吉兆→尊长老人分上有喜庆；坤方见克→老母阴人有灾；震方水生→长子长孙喜；坎方宜五金吉兆→中男喜；离方木生→中女喜；艮方火生→少男喜；兑方土生→少女喜。问病则"乾受克病在头、坤受克病在腹、震足巽股、离目坎耳血、艮手指、兑口齿"。

**二、加数诀（同卦别断）**
同一时间多人多事起得**同一卦**时，吉凶莫辨——须"加数"区分：加姓氏画数（或声音、所寓）到原数里再起卦。起屋加本姓，婚姻加二姓，极北无名者以声音/所寓代之。各依本家之卦断，应期亦各家不同（如田姓水风井、王姓雷火丰、韩姓风雷益，毁期各别）。

## A1 — 书中的应用 (Past Application)

### 案例 1：三家同日起造，加姓别断
- **问题**：寅年十二月初一午时，邻市三家同求占起造，若同卦则吉凶莫辨。
- **用法**：加姓画数——王姓4→雷火丰变震，互兑巽；田姓6→水风井变升，互离兑；韩姓21→风雷益变中孚，互艮坤。
- **结论**：各依本家卦断，王姓火年月有损、田姓逢坎水进益、韩姓酉年官讼。
- **结果**："不特起屋之年月日時加姓也，凡冠婚及葬事皆加一姓可矣"，皆验。

### 案例 2：坐端定病位
- **问题**：问病，如何快速定病在何处？
- **用法**：依所坐八方，乾受克病在头、坤受克病在腹，推之震足巽股离目坎耳及血艮手指兑口齿。
- **结论**：于其克者定见其病。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 多人/多事在同一时辰起占，怕"同卦混断"时（加数诀）。
2. 占卜现场想用"自己落座方位 + 八方应兆"快速定各家吉凶/病位时（坐端诀）。
3. 读到"坐端""加姓""加数"术语时。

### 语言信号
- "同一时间起卦怎么区分""同卦怎么断""加姓氏画数""坐端诀""以坐为中定八方""梅花易数 加数例"
- "how to differentiate same gua / zuo-duan / add surname count"

### 与相邻 skill 的区分
- 与 `qigua-xiantian`：本卡是"同卦如何加数区分"，那张是"基础起卦"。加数是起卦的变体。
- 与 `san-yao-shi-ying`：坐端"八方应兆"与外应同源，但坐端特指"以坐定中宫排八方"的格局法。

## E — 可执行步骤 (Execution)

### 坐端诀
1. **定中宫**：以占者所坐为中央。
   - 完成标准：中宫确立。
2. **排八方**：乾西北兑西离南震东巽东南坎北艮东北坤西南。
   - 完成标准：八方卦位图在胸。
3. **察各方应兆**：看何方有生体之卦气/吉兆/人物，定对应家分（长幼/阴阳）吉凶。
   - 完成标准：各分吉凶标注。
4. **定病位**：若有克，依"乾头坤腹震足巽股离目坎耳血艮指兑口齿"定病所。

### 加数诀
1. **冲突识别**：多事同卦，须区分。
   - 完成标准：确认同卦冲突。
2. **加数**：本姓/二姓画数（或声音、所寓）加到原数再起卦。
   - 完成标准：各家独立卦成。
3. **分断**：各依本家卦断吉凶与应期。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 单次单人起卦、无同卦冲突 → 不需加数，用基础起卦。
- 非占卜现场、无八方格局 → 坐端诀无从施展。

### 作者在书中警告的失败模式
- 同卦不加分晓："若同一卦，則吉凶莫辨矣"——必须加姓/加名/加所寓（卷二·起卦加数例）。
- 坐端须"虚心待應"：先入为主则八方应兆失真。

### 作者的盲点 / 时代局限
- 加数本质是"用更多信息打破同卦歧义"，但加什么数（姓画/声音）仍是约定，非必然。

### 容易混淆的邻近方法论
- 加数与先天"年月日时起卦"同属起卦变体；坐端与三要十应同源但格局化。

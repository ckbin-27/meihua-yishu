# 三要十应（外应体系）

## R — 原文 (Reading)

> 三要者，運耳、目、心三者之要也。靈應者，靈妙而應驗也。夫耳之於聽，目之於視，心之於思，三者為人一身之要……占決之際，寂聞澄慮，靜觀萬物，而聽其音，知吉凶，見其形，知善惡。
> — 卷二·体用生克篇之三·三要灵应篇

> 十應並以體卦為主，諸用卦為用。每以內分外體，用卦參觀為妙。內卦不吉而外卦又吉，可以解其不吉；內卦吉而外卦不吉，反破其吉。
> — 卷二·十应目论

---

## I — 方法论骨架 (Interpretation)

梅花易数不止看卦，还要看"占卜当下发生的一切"——这叫**外应**。外应来自"三要"：耳（所闻之声）、目（所见之形）、心（所念之意）。占卜时耳闻、目见、心念的吉凶征兆，都要与内卦（体用）合参。

**十应**是把外应系统化的十一类（卷二·十应目论 + 卷三·占卜十应诀）：
1. 正应（体用二卦本应）2. 互应 3. 变应 4. 方应（来人方位）5. 日应（本日卦气）6. 刻应（三要即时兆）7. 外应（偶见外物）8. 天时应（晴雨风雷）9. 地理应（竹林江河窑灶）10. 人事应（老幼男女吉凶事）11. （附）言语/声音/五色/写字等。

**合参铁律**：内卦（体用）与外应须合断——内吉外凶可破吉、内凶外吉可解凶；全吉全凶则断然。金银世宝三要以为祥、十应或凶；利刃兵刃三要以为凶、十应或吉——须以体卦五行真生真克分轻重（卷二·十应奥论）。

## A1 — 书中的应用 (Past Application)

### 案例 1：邻夜叩门借物（言语/声音外应）
- **问题**：扣门一声又五声，云借物。
- **用法**：一声乾、五声巽加酉时→天风姤，金短木长。子断"锄"，先生以"夕晚安用锄"的理（心念外应）改"斧"。
- **结论**：外应之理胜数。
- **结果**：果借斧。

### 案例 2：三要与十应相左（占产见少男 / 占疾见棺）
- **问题**：占产见少男、占疾见棺，三要吉而十应凶，如何？
- **用法**：占产少男为艮土，若体为坎水，土克水→反不吉（十应胜三要）；占疾见棺，若体为离火，木生火→反吉（十应胜三要）。
- **结论**：内卦外应合参，不可单取一端。

## E — 可执行步骤 (Execution)

1. **记三要**：占时耳闻（声笑语哭）、目见（人/物/色/天象）、心念（己身忧乐）逐一记下。
   - 完成标准：外应清单。
2. **归类十应**：把外应归入方/日/天时/地理/人事/言语/声音/五色/写字等类。
   - 完成标准：外应分类。
3. **合内卦**：以体卦为主，看外应生体/克体/比和。
   - 完成标准：外应相对体卦的生克。
4. **定胜负**：内吉外凶→可破吉；内凶外吉→可解凶；全同则断然；真生真克分轻重。
   - 完成标准：综合结论。
5. **矛盾时取理**：若仍矛盾，交 `lilun-biantong` 以"理"裁决。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 静室无闻见、纯静占 → 不论外应，仅本卦体用+旺衰（卷二·静占）。
- 还没起卦分体用 → 先 `ti-yong-fen`。

### 作者在书中警告的失败模式
- **单看三要或单看十应**："內卦不可無外卦，外卦不可無內卦"——偏废则鲜验（卷二·内外论）。
- **圆成缺败机械套**：金银世宝、利刃兵刃等需合体卦五行真生真克，不可死守常理（卷二·十应奥论）。
- **向背不分**：外应以"来/去"判时态——鸦来灾将至、鸦去灾已过；生体之卦方来则吉、去则吉已过（卷二·向背）。

### 作者的盲点 / 时代局限
- 外应高度依赖解卦者主观拣选，"见吉则吉"易陷入确认偏误。

### 容易混淆的邻近方法论
- 端法"见物起卦"（起卦阶段）与本卡"见物为外应"（断卦阶段）不同，勿混。

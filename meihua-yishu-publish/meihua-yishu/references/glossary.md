# 术语词典 —《梅花易数》

> 摘自全书，按"起卦 → 读卦 → 断卦 → 应期 → 外应 → 取象"的认知顺序编排。术语在正文能力卡中首次出现时不再逐条重释，查此表即可。

## 一、数→卦的基础映射

**八卦数（先天数）**
乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。起卦时数过八则除八取余（数恰为八取坤，不必除）。这是"先天起卦"与"后天端法"共用的定卦算法。

**五行生克**
相生：金生水、水生木、木生火、火生土、土生金。
相克：金克木、木克土、土克水、水克火、火克金。
八宫五行：乾兑金、坤艮土、震巽木、坎水、离火。

**方道（八卦方位）**
离南、坎北、震东、兑西、巽东南、乾西北、艮东北、坤西南。后天端法与坐端诀均以此为空间坐标。

## 二、读卦的构件

**体 / 用**
成卦中无动爻者为**体**（主、己身之兆、所占之自我），有动爻者为**用**（事、应事之端、所占之外物）。体用之分是断卦的总开关。

**互卦**
去本卦初爻与上爻，取中间四爻分作两卦，为"事之中应"（事情发展的中段）。乾坤无互则互其变卦。

**变卦（之卦）**
动爻阴阳互变所得之卦，为"事之末应/终应"。代表事情的最终走向。

**比和**
体用五行同类（如金与金、木与木），百事顺遂，属吉。比和是最稳的吉兆，因"我"与"事"同心。

## 三、起卦的两条路径

**先天之数 / 后天之数**
- 先天 = 未得卦先得数，以数起卦（**数→卦**）：年月日时、物数、声音、字数、丈尺皆此路。
- 后天 = 先得卦后起数，以卦起数（**卦→数**），即"端法"：先见物象/方位再配时数。

**端法**
后天起卦法：以所见物为上卦、物来方位为下卦，合物卦数 + 方位数 + 时数取动爻。是"临机取象"的核心。

## 四、断卦与应期

**卦气旺衰**
- 旺：春震巽木、夏离火、秋乾兑金、冬坎水、四季（辰戌丑未月）坤艮土。
- 衰：为其对冲之季。
- 断诀：**体宜乘旺、克体宜衰**。体卦当时则盛，克体之卦失时则无力为害。

**克应（应期）**
克期应验，即吉凶"应于何时"。由占者坐行卧立之态、卦数、以及生体/克体卦气所值之年月日时共同决定。坐则迟、行则速、立则半、卧则伏。

**物数为体诀**
算物数时不止以本卦为体，卦之多者（如乾金数多）亦可作体，看刚柔生旺定物性。多见于射覆、观物之占。

## 五、外应与变通

**三要**
耳（闻）、目（见）、心（念）三者之虚灵，是占时"外感内省"的外应来源。占时闻见之兆，须与内卦合参。

**十应**
天时、地理、人事、时令、方卦、动物、静物、言语、声音、五色、写字十类外部征兆。内卦与外应合参，内吉外凶可破吉、内凶外吉可挽凶。

**理在数先 / 不動不占**
元规则：卦数须以常理、时令、语境来校正（理在数先）；无"动、怪、异、问"之兆则不动念占测（不動不占）。不可死执一法，亦不可因事而妄测。

---
*术语来源：卷一·周易卦数/八卦万物属类、卷二·体用总诀/三要灵应篇、卷三·体用衰旺之诀/占卜克应之诀/论理变通等。*

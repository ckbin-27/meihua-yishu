# 决策规则速查 — 梅花易数

| 能力 | 一句话规则 |
|---|---|
| 先天起卦法（数→卦） | 数过八除八取余定卦、总数除六取余定动爻（乾1…坤8）。 |
| 后天起卦法（物象+方位端法，含字占） | 所见物为上卦、来方为下卦，合物+方+时数除八取余定动爻。 |
| 体用分卦与互变 | 无动爻为体、有动爻为用；本卦即应、互卦中应、变卦末应。 |
| 五行生克断诀 | 用生体/比和/体克用吉，用克体凶，体生用泄气非利；看体党用党与旺衰。 |
| 卦气旺衰与应期（克应） | 体宜旺克体宜衰；坐迟行速立半；生体之日为吉期、克体之日为凶期。 |
| 十八占分类断法 | 每占类先定"体=什么、用=什么"再套生克；失物查变卦方位、疾病查克体定医药。 |
| 三要十应（外应体系） | 耳闻目见心念为三要，天/地/人/时令/方/动/静/言/声/色为十应，与内卦合参。 |
| 八卦万物类象（取象辞典） | 乾天父金西北、坤地母土西南…八象对应人/物/方/色/行，供起卦与取义两用。 |
| 射覆观物法 | 以变爻为主、体用生克定物性（生体可食/克体秽/比和成器）；物数为体、趣时、引辞。 |
| 论理变通（心易玄机/先后天/理在数先） | 不動不占、理在数先、先后天用辞有别、不拘死法，以理校数。 |
| 坐端诀与加数诀（进阶操作） | 坐端以坐定中宫排八方定各家吉凶/病位；加数加姓氏画数破同卦歧义。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
